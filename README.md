
# Mastery Workforce PEO Limited — Website

Marketing/recruitment website for Mastery Workforce PEO Limited, a recruitment
and HR specialist company serving organisations across Africa.

## Tech Stack

- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS v4
- **Fonts:** Sora (headings), Inter (body) — via `next/font/google`

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it.
